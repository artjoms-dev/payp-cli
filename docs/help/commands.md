# payp Commands

All commands start with `/`. Everything else is natural language to the AI.

## Connection
- `/db` — manage database connections
- `/db <name>` — connect to named connection

## AI
- `/models` — show/add AI providers
- `/models check [openrouter]` — verify key works and show usage/balance metadata
- `/mode` — show available modes
- `/mode <name>` — switch security mode

## Data
- `/schema` — explore schema
- `/snapshots` — manage backups
- `/history` — view SQL audit log

## Session
- `/cost` — token usage and costs
- `/export` — export hint
- `/help` — show commands
- `/quit` / `/exit` — leave payp

## Keyboard shortcuts
- `Ctrl+C` — cancel current operation
- `Ctrl+D` — exit payp
- `↑ / ↓` — navigate input history
